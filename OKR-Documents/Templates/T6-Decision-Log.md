## Decision Categories

Use these tags in the "Context" column for easy filtering:

| Tag | Meaning |
|---|---|
| `SCOPE` | Scope change — feature added, removed, or modified |
| `PRIORITY` | Priority shift — reordering of tasks or KRs |
| `RESOURCE` | Resource allocation — people, time, or budget |
| `TECH` | Technical architecture or tool choice |
| `CLINICAL` | Clinical/medical methodology decision |
| `SALES` | Sales strategy, pricing, or deal-specific |
| `CUT` | Something removed from scope (reference A7 Cut List) |
| `ESCALATION` | Triggered by red flag or blocker |
