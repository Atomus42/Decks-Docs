## Demo Script Outline

| Segment | Duration | Content | Presenter |
|---|---|---|---|
| **Opening** | 2 min | "The problem: BRA teams juggle 5+ tools for compound data. We fixed it." | CEO |
| **Platform Context** | 3 min | Quick BRA platform overview — the 5-step pipeline | Vassili |
| **Compound Search** | 3 min | Search a real compound. Show structure, properties, classification | Vassili |
| **ADMET** | 3 min | Run ADMET prediction. Show safety profile fed into B&R Assessment | Vassili |
| **Mechanism** | 2 min | Drug-target interaction. Pathway map. How it enriches Context step | Vassili |
| **Bioactivity** | 2 min | IC50/EC50, dose-response. Feeds Data Analysis | Vassili |
| **Drug-Target Binding** | 2 min | Binding affinity. Off-target flags. Decision-Support input | Vassili |
| **Full Integration** | 3 min | Show the complete BRA with chem data flowing through all 5 steps | Vassili |
| **Pricing + CTA** | 2 min | "Here's how to get started." Module pricing. Book a demo | CEO |
| **Q&A** | 10 min | | CEO + Vassili |
