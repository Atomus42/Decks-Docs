# T4 — Weekly PM Best Practices (6-Week Sprint)

> A checklist for the person running the sprint (CEO or designated PM). Execute every week without exception.

---

## Monday (Sprint Week Kickoff Day)

- [ ] Review B1 scorecard — all KRs updated from last week?
- [ ] Check phase: Finalize (Wk1–2) / Launch (Wk3–4) / Close (Wk5–6) — are we on track for the phase gate?
- [ ] Run 15-min Sprint Week Kickoff: each person states top 3 priorities
- [ ] Unblock: any dependency or blocker that was raised Friday → resolve by EOD Monday
- [ ] Calendar check: all recurring meetings (C1) still on schedule this week?

## Tuesday (Pipeline Day)

- [ ] Run 30-min Pipeline Review with CEO + team
- [ ] Update B3 Pipeline Tracker — every deal reviewed
- [ ] Check coverage ratio — if < 2x → escalation protocol
- [ ] Update deal stages — any progressions or stalls?

## Wednesday (Chemical Analysis Day)

- [ ] Run 30-min Chemical Analysis Standup
- [ ] Update B6 i-Demo Launch Tracker
- [ ] Check sub-module deployment status vs. plan
- [ ] Validate case study progress

## Thursday (Quality Day)

- [ ] Run 60-min Fixing session — F1 scores, credibility, noise, calibration
- [ ] Update KR1.2 F1 scores in B1
- [ ] Review O1 Definition of Done criteria — are we on track?

## Friday (Forecast Day)

- [ ] CEO updates B2 Revenue Dashboard
- [ ] Review forecast: Commit / Best Case / Upside
- [ ] Review Red Flags from B1 — any triggered?
- [ ] Prepare next week: meetings confirmed, proposals queued, demos scheduled

---

## End-of-Week Reflection (5 min, solo)

1. Did we move the needle on the sprint's critical path this week?
2. What's the #1 risk going into next week?
3. Is anything slipping that I'm not acknowledging?
