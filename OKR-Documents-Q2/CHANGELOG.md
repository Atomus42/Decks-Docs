# CHANGELOG — OKR2 vs. OKR1

> Summary of structural and content differences between the OKR1 (Q1 2026, 12-week) and OKR2 (Q2 2026, 6-week sprint) packages.

---

## Cadence Change: 12 Weeks → 6 Weeks

- All scorecards, dashboards, and timelines now show **Wk1–Wk6** (not Wk1–Wk12)
- Sprint phased as **Finalize (Wk1–2) / Launch (Wk3–4) / Close (Wk5–6)** instead of 6 bi-weekly phases
- Phase gates added at Wk2 and Wk4 with explicit pass/fail criteria
- Sales operating system (C3) durations compressed: max stage duration shortened, disqualification triggers tightened
- Monday Sprint Week Kickoff meeting added to weekly cadence (C1)

---

## O1 — BRA Platform: Expanded Scope

| OKR1 | OKR2 |
|---|---|
| 3 BRA pipeline steps (Context, B&R Assessment, Data Analysis) | **5 steps** (+ Reporting, Decision-Support) |
| F1 target: ≥ 85 % | F1 target: **≥ 90 %** |
| Human work: < 4 h per step | Human work: **< 1 h total** (all steps combined) |
| Availability: 99 % | Availability: **99.5 %** |
| Code coverage: 80 % | Code coverage: **85 %** |
| 6 Definition of Done criteria | **7 criteria** (+ End-to-End Smoke Test) |

## O2 — New Objective: i-Demo Chemical Analysis

| OKR1 O2 | OKR2 O2 |
