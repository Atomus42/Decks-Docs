# Appendix A — Key Definitions

| Term | Definition |
|---|---|
| **ARR** | Annual Recurring Revenue — annualized value of all active subscriptions at sprint end. €125k contract signed in Wk5 = €125k ARR (not prorated) |
| **ACV** | Annual Contract Value — the annual value of a single contract |
| **Qualified Opportunity** | Deal at S2+ with confirmed pain, champion, process, and budget discussion (MEDDPIC all confirmed) |
| **BRA Pipeline** | The five-step process: Step 1 "Context" → Step 2 "Benefit & Risk Assessment" → Step 3 "Data Analysis" → Step 4 "Reporting" → Step 5 "Decision-Support" |
| **Definition of Done (O1)** | Data Quality Validation + Data Traceability + Platform Usage Analysis + Platform Perf Monitoring + Code Quality Gate + 85 % Code Tested + End-to-End Smoke Test — all seven criteria |
| **Definition of Done (O2 — per Case Study)** | Chem pipeline runs end-to-end + External Validation + Internal Validation + LLM Validation + Integrated in BRA + Demo-Ready — all six criteria |
| **F1 Score** | Harmonic mean of precision and recall — used to measure accuracy of endpoint extraction pipelines |
| **Pipeline Coverage** | Qualified pipeline € / remaining revenue target. Minimum 3x |
| **BRAT** | Benefit-Risk Action Team framework (regulatory standard) |
| **CIOMS** | Council for International Organizations of Medical Sciences |
| **APM** | Application Performance Monitoring — tracks user actions, errors, treatment time, cost |
| **SonarQube Quality Gate** | Automated code quality check that all Prod deployments must pass |
| **ADMET** | Absorption, Distribution, Metabolism, Excretion, Toxicity — the five key pharmacokinetic properties used to profile compound safety and viability |
| **Mechanism of Action (MoA)** | How a drug produces its pharmacological effect — the specific biochemical interaction through which a drug substance produces its pharmacological effect |
| **Bioactivity** | The effect of a compound on living organisms — measured by IC50/EC50, dose-response curves, selectivity profiling |
| **Compound** | A chemical substance with a specific molecular formula — in this context, a drug or drug candidate identified by name, SMILES, or InChI notation |
| **SMILES** | Simplified Molecular-Input Line-Entry System — a line notation for describing the structure of chemical species |
| **InChI** | International Chemical Identifier — a textual identifier for chemical substances |
| **Drug-Target Binding** | The interaction between a drug molecule and its biological target (receptor, enzyme, etc.) — measured by binding affinity (Kd) and selectivity |
| **IC50 / EC50** | Half maximal inhibitory/effective concentration — the concentration of a compound required to inhibit/activate 50 % of the biological process |
| **i-Demo** | ArcaScience's interactive demonstration product — a publicly accessible, live walkthrough of platform capabilities used for lead generation and sales |
| **Top-10** | The 10 named strategic target accounts: Sanofi, Roche, Novartis, AstraZeneca, GSK, Bayer, Boehringer Ingelheim, Servier, Ipsen, UCB |
| **Biotech Long-Tail** | Smaller biotech companies (< $5B revenue) with faster sales cycles (20–45 days) and lower ACV (€40k–€80k) — volume play to complement Top-10 strategic deals |
| **Multi-Year Deal** | A contract with a term of 2+ years — accelerated with 10 % (2yr) or 15 % (3yr) discount |
