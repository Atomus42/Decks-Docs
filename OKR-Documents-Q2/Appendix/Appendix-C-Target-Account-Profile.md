# Appendix C — Target Account Profile (TAP)

Use this to qualify whether an account belongs on the target list:

---

## Top-10 Strategic Account Criteria (all 6 required)

- [ ] Pharma/biotech with 5+ active clinical programs
- [ ] Has pharmacovigilance or benefit-risk function
- [ ] Currently doing BRA manually (Excel, Word, consultants) or with fragmented tools
- [ ] Budget authority at VP/Director level accessible within 2 contacts
- [ ] European HQ or strong European operations (accessible from France)
- [ ] Annual R&D budget > €500M

**If all 6 checked → Top-10 candidate. If 5/6 → strong candidate. If < 5 → Biotech Long-Tail or pass.**

---

## Biotech Long-Tail Criteria (4 of 6 required)

- [ ] Biotech with 1+ active clinical programs
- [ ] Has regulatory or pharmacovigilance need
- [ ] Currently doing BRA manually
- [ ] Budget authority accessible (CEO/Head of Regulatory for small biotech)
- [ ] Decision cycle < 45 days
- [ ] Annual R&D budget > €10M

**If 4+ checked → add to Long-Tail target list. If < 4 → pass.**
