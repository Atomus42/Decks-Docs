# A2 — The Value Chain: How O1 → O2 → O3 Compound

```
O1 (Finalize Platform)  ──►  O2 (i-Demo Chem Launch)  ──►  O3 (€500k Revenue)
      ENGINE                     ACCELERATOR                   OUTCOME
```

| Link | Mechanism | What Breaks if It Fails |
|---|---|---|
| **O1 → O2** | Production-grade BRA pipeline provides the foundation the chemical-analysis module plugs into | Chem module has no host platform — i-Demo launch is a standalone demo with no commercial value |
| **O2 → O3** | i-Demo launch generates buzz, ≥ 50 qualified leads, and a compelling demo asset that compresses sales cycles | We're selling a platform without a differentiator — longer cycles, lower win rate, lower ACV |
| **O3 → O1** | €500k revenue proves commercial viability, funds next engineering cycle | Platform roadmap stalls. No investment in scale, no enterprise features |
| **O1 → O3** | F1 ≥ 90 % and < 1 h per BRA = credible demo → faster closes | Demos fall flat, prospects ask "is this really production-ready?" |
| **O2 → O1** | Chemical-analysis module extends BRA scope (ADMET in B&R Assessment, bioactivity in Data Analysis) | Platform stays narrow, chemical-analysis is bolt-on instead of integrated |

**Critical path for 6 weeks:**
- O1 platform steps must be in Prod by **Wk2** (Finalize phase) so O2 can integrate
- O2 module must be demo-ready by **Wk3** so launch happens in **Wk4** (Launch phase)
- O2 leads feed O3 pipeline starting **Wk4** to close in **Wk5–6** (Close phase)
